# 日麻风盘（中英文修改版）

本项目基于 [Riichi Tracker](https://github.com/1Computer1/riichi-tracker)，保留四向风盘和自动点数结算，并增加中英文界面、PT 结算和本地历史。修改版源码：[Apric1ty-y/-](https://github.com/Apric1ty-y/-)。

修改日期：2026-10-14。原项目及第三方素材的许可证声明均保留。

## 功能

- 四向场风盘与四家点数显示
- 点数、本场和供托的手动增减
- 点击玩家风牌进行荣和或自摸结算
- 直接输入番数与符数，自动完成点数转移
- 荒牌流局、途中流局与犯规结算
- 四人麻将和三人麻将
- 手机与电脑适配、中英文切换
- 切上满贯开关及立直、和牌、放铳次数
- 对局结束确认、走势图和每局结算详情
- 可配置素点、马点、丘点及同分处理的 PT 结算
- 一次保存到所有参与者的本地历史
- 可安装的 PWA，部署到 HTTPS 后支持离线使用

目前没有登录或云同步。历史保存在浏览器 IndexedDB；更换设备、网址或清理浏览器数据可能导致原记录不可用。详见 [数据与规则说明](MATCH-RESULTS.md)。

## 在电脑上运行

先安装 Node.js，然后在项目目录执行：

```powershell
npm ci
npm run dev
```

浏览器访问终端显示的本地地址。

## 在同一 Wi-Fi 下用手机访问

在电脑上执行：

```powershell
npm ci
npm run dev -- --host 0.0.0.0
```

使用 `ipconfig` 查看电脑的 IPv4 地址。假设地址为 `192.168.1.20`，手机访问：

```text
http://192.168.1.20:5173
```

电脑和手机必须连接同一个局域网，并允许 Node.js 通过 Windows 私有网络防火墙。电脑关闭或停止开发服务器后，手机将无法继续访问。

## 构建可部署版本

```powershell
npm run build
```

生成文件位于 `dist` 目录。将该目录部署到支持 HTTPS 的静态网站后，可在手机浏览器中选择“添加到主屏幕”，并使用离线缓存。

本项目沿用原项目的 AGPL-3.0-only 许可证。对外提供修改版网络服务时，应同时提供对应源代码。

## Netlify 自动部署

连接本修改版 GitHub 仓库，构建命令填写 `npm run build`，发布目录填写 `dist`，使用支持当前 Vite 的 Node.js 版本（建议 Node.js 24）。当前使用 HashRouter，网址形如 `/#/compass`，无需为这些 hash 路由配置服务器重写。生产运行不需要 Node.js 开发服务器。
